# Carver Guardian 3D V3 — Code Rescue

Deploy as a static site on Vercel (no build step). Upload `index.html` and `vercel.json` to the root of the existing GitHub repository.

## Updates
- Third-person follow camera behind the hero; swipe on the game world to orbit.
- More detailed cafeteria with benches, lights, serving counter, and banners.
- Improved armor details, corrected front-facing CG emblem and CARVER hat lettering.
- Performance/Quality graphics toggle (Performance recommended on older laptops and phones).
- Aligned mobile direction controls, working ACTION mission sequence, touch zoom prevention.

## Limitations
The character is still a procedural stylized 3D approximation. A lifelike facial match and modern-console realism require a separately created/rigged 3D model and optimized textures; this release does not claim to deliver them. Three.js is loaded from a CDN, so the game needs an internet connection.
